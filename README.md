# nullsec
A menu-driven security multitool — recon, password cracking, crypto and cipher breaking, forensics, steganography, OSINT, and web testing, all behind one prompt. Most of it runs on pure Python with no setup, while heavier tools like nmap, hydra, nuclei, and metasploit light up automatically once they're installed. See [USAGE.md](USAGE.md) to get it running.
